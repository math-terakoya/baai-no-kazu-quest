集合の 記号

・A∪B（または）：A と B の 少なくとも 一方に 入る もの
・A∩B（かつ）：A と B の 両方に 入る もの
・A∩B ＝ ∅（排反、重なりが ない）の ときは、A∪B は A か B の どちらか 一方に 入る もの
・A（でない）：全体 U の うち A に 入らない もの（補集合）
・3 ∈ A：3 は A の 要素、B ⊂ A：B は A の 部分集合
・n(A)：A の 要素の 個数
